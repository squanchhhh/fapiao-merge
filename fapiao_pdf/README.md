# 测试样例（不入库）

这个目录用来放**你自己**的发票 PDF，仅供本地测试使用。

`tests/parse.test.ts` 和 `tests/merge.test.ts` 会读取这里的文件；文件不存在时，依赖样例的用例会自动跳过，其余单元测试照常运行。

> **请不要把真实发票提交到 Git。**
> 发票 PDF 里通常有姓名、单位、税号、金额、行程和住宿信息，一旦推到公开仓库就无法真正删除。
> 本目录的 `*.pdf` 已被 `.gitignore` 排除；提交前可以运行 `git status` 和 `git ls-files fapiao_pdf` 复核。

需要跑完整测试时，放入以下文件（文件名需一致）：

- `发票-1.pdf`：铁路电子客票
- `发票-4.pdf`：数电普通发票
- `发票-3.pdf`、`发票-9.pdf`、`发票-10.pdf`：不同文字层结构的数电普票
